# The Block Viewer name and logo

Block Viewer is free software under the GNU General Public License, version 3
or later ([LICENSE](LICENSE), [NOTICE.md](NOTICE.md)). That licence covers
copyright: anyone may study, change and share the code. It does not cover
trademarks. This page says how the project's name and logo may be used, so
that people always know which builds come from the Block Viewer team.

## The marks

- the name **Block Viewer**, and **Aurora** when it names this viewer;
- the Aurora wolf logo and silhouette, in every colour and size
  (`assets/branding/`).

The logo files stay under the GPLv3 like the rest of the repository; this page
only covers their use as the mark of a product.

## Fine without asking

- Building and running Block Viewer from these sources for yourself.
- Sharing unmodified builds of an official release under its name, or packages
  for an operating system that only change what packaging needs.
- Saying truthfully that a project is **based on**, **derived from** or
  **compatible with** Block Viewer.
- Talking about Block Viewer with its name and logo: articles, reviews,
  tutorials, videos, links to the official downloads.

## Needs our written agreement

- Distributing a modified version under the name Block Viewer, or with the
  Aurora logo as its icon, splash screen or brand.
- A name or logo close enough to Block Viewer's to be mistaken for it.
- Presenting a project, a build or a service as official, endorsed by or
  affiliated with Block Viewer when it is not.

## Modified versions

A modified version uses its own name and icon. As the GPLv3 requires, it keeps
the copyright and licence notices of Block Viewer (section 4), including the
notices shown in the About window (section 5(d)), and says that it was modified
and when (section 5(a)).

## Official downloads

The only official builds are those linked from
[block-viewer.org](https://block-viewer.org) and the
[releases of this repository](https://github.com/Aurora-Viewer/Aurora-Viewer/releases).
