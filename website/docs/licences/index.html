Media plugins

Web pages and video on media faces go through a separate pack, built by the “Media plugins” workflow (.github/workflows/media-plugins.yml) and published as the GitHub releases media-plugins-<n>. The viewer downloads it when media need it and installs it in the user’s data folder. Each release attaches the license texts (LICENSES\ in the archive) and the corresponding source of the Linden Lab code. On Linux, video plays through the system’s GStreamer, which the pack does not include.
