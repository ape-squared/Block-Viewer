Before you install

What you need before you unpack the zip.

OS
Windows 10 or 11, 64-bit
GPU
Vulkan-capable graphics (recent NVIDIA / AMD / Intel)
Disk
Room for the zip plus cache under LocalAppData
Account
A Second Life account (or another grid you configure)

After download

  1. Unpack Extract Block-Viewer-v…-windows-x64.zip to a folder you control.
  2. Launch Run block-viewer.exe. First start may compile pipelines — give it a moment.
  3. Log in Choose Second Life (or another grid), pick a start location, connect — or open demo mode offline.

  • What’s in the zip

    Executable, licences, README, and asset licences. Optional Uninstall.cmd. No installer required.

  • Config location

    %LOCALAPPDATA%\ape-squared\BlockViewer\ and %APPDATA%\ape-squared\BlockViewer\

  • Not Block (GPPI)

    This is the viewer. Post-processing for other clients lives at Block-GPPI — different download.

  • Privacy

    No project telemetry server of our own. Grid traffic goes to the grid you choose. See the privacy page.
