Privacy

Block Viewer has no project telemetry server of its own. Grid traffic goes to the Second Life (or other) grid you choose. Updates and crash symbols use GitHub Releases for this repository when enabled.

Login & world

Credentials and session traffic go to the login URI and region you select. Device identifiers follow the Legacy Viewer login fields. We do not operate a proxy for that traffic.

On this computer

Settings, cache, chat logs (if enabled), and remembered login hashes live under %LOCALAPPDATA%\ape-squared\BlockViewer\ (and the system credential store for passwords / MFA).

Updates

When “check for updates” is on, the viewer asks GitHub for ape-squared/Block-Viewer releases and may download a zip you accept.

Sister products

Block-GPPI is a separate injector with its own site and issues. This policy is for the viewer only.
