Roadmap

A living sketch of where Block Viewer is headed — not dates, not a contract. Tester reports and GitHub issues move things up or aside. Ship when it is useful.

Discord · Testers hub · GitHub issues

Third-party viewer

Block Viewer is an independent Third Party Viewer (TPV). We are contemplating whether to pursue Linden Lab’s TPV verification — nothing here claims we are verified today.

Caution around unknown viewers is reasonable. We do not pressure or guilt anyone into switching. Use Block only if you choose to; the official viewer and other TPVs remain valid options.

  1. now

    Polish & reliability

    • Bug pressure from the grid Triage crashes, HUD clicks, friends-only, chat visibility, and whatever testers hit next.
    • Release cadence Keep Windows and macOS GitHub Releases moving with SemVer tags when something useful lands.
    • Tester loop Discord, the testers hub, and in-viewer report paths so feedback becomes tracked issues.
  2. next

    Platform & creator flow

    • macOS & Linux maturity Mac builds already ship; keep hardening. Linux stays docs-first until packaging is honest.
    • Imports & LiveMesh Smoother asset import and live mesh workflows for people building looks and props.
    • RLVa coverage Grow protocol support where testers need it, without pretending full parity overnight.
  3. later

    Deeper passes

    • Performance & memory Avatar load, texture budgets, and long-session comfort on real hardware.
    • Environment & media Richer sky/water/media tools when the core loop is boringly solid.
    • Whatever the grid demands This list bends toward Discord and GitHub — features earn their place.
  4. shipped

    Already in 0.x

    • Vulkan world view Login, destinations, MFA, nearby chat / IM / groups / voice.
    • Inventory & appearance Outfits, AO, People / radar, environment tools, auto-update from Releases.
    • Recent polish Friends-only Controls, chat bar / nearby visibility, HUD click fixes, Mac releases, testers hub + site.

Built on the open-source Aurora Viewer lineage. Want something on this list moved up? File it from the testers hub.
